Команды для запуска:

For Linux or MacOS (UNIX):
gcc child.c -o child && gcc parent.c -o parent && ./parent <delay_sec>

For Windows:
gcc child.c -o child.exe && gcc parent.c -o parent.exe && parent.exe <delay_sec>
